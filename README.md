# Oral-Immunotherapy-Safety-Tracker -- Python
## Biological Question
Can we predict the safety of a patient's next Oral Immunotherapy (OIT) dose based on their OIT data and reaction history?
## Project Description
Analyzes patient Oral Immunotherapy (OIT) data to assist in tracking adverse reactions and determining if a patient can safely increase to the next dose.
## Input
CSV of patient logs containing dates, dose amounts consumed, and reaction severity scores.
## Output
Text summary of recommendation on whether to increase, maintain, or reduce the dose. And a graph of reaction trends over time.
